One or more temporary surges of skill applied to an associated skill. Where a Boon is a fixed standing adjustment, a Boost is a reserve of extra mastery a character can draw upon, raising the associated skill while the Boost lasts. A Boost may name a skill the character does not yet possess, in which case the skill is offered to the character (at an unlearned, beginner rating) so the Boost has something to lift. Like a Boon, a Boost can apply to any tradition's skill.
